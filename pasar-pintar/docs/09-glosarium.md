# 09 — Glosarium

## Matematika (Aritmetika Sosial)

| Istilah | Arti |
|---|---|
| Harga Beli (HB) | Harga ketika pedagang membeli barang (dari pabrik, grosir, petani) |
| Harga Jual (HJ) | Harga ketika pedagang menjual barang ke pembeli |
| Untung / Laba | Selisih HJ − HB jika HJ > HB |
| Rugi | Selisih HB − HJ jika HB > HJ |
| Impas | HJ = HB, tidak untung dan tidak rugi |
| Persentase untung/rugi | Untung atau rugi dibandingkan HB, dikali 100% |
| Harga Awal | Harga barang sebelum diskon |
| Diskon | Potongan harga dalam persen |
| Potongan | Besar diskon dalam rupiah |
| Harga Setelah Diskon / Harga Akhir | Harga Awal − Potongan; yang dibayar pembeli |
| Diskon bertingkat | Beberapa diskon berurutan; diskon kedua dihitung dari harga setelah diskon pertama |
| PPN | Pajak Pertambahan Nilai, dihitung dari harga (setelah diskon) |
| Bruto, Neto, Tara | Berat kotor, berat bersih, berat kemasan (Bruto = Neto + Tara) |
| Bunga tunggal | Bunga yang dihitung hanya dari modal awal |
| Kodi | 20 buah |
| Lusin | 12 buah |

## Pedagogi

| Istilah | Arti |
|---|---|
| Teori Beban Kognitif (CLT) | Teori tentang keterbatasan memori kerja dalam belajar |
| Beban intrinsik (IL) | Beban dari kerumitan materi |
| Beban ekstrinsik (EL) | Beban dari cara penyajian yang kurang baik |
| Beban germane (GL) | Usaha mental yang membangun pemahaman (skema) |
| Skema | Struktur pengetahuan di memori jangka panjang |
| Worked example | Contoh soal dengan penyelesaian lengkap |
| Faded example / Contoh rumpang | Contoh yang sebagian langkahnya dikosongkan |
| Scaffolding | Bantuan sementara yang dikurangi bertahap |
| Split-attention | Beban karena harus memadukan informasi yang terpisah letaknya |
| Signaling | Penanda visual untuk mengarahkan perhatian |
| Segmenting | Memecah materi menjadi bagian kecil |
| Pre-training | Mengenalkan istilah/konsep kunci lebih dulu |
| Expertise reversal | Bantuan untuk pemula bisa mengganggu siswa yang sudah mahir |
| Self-explanation | Siswa menjelaskan langkah atau alasan kepada dirinya sendiri/orang lain |
| Skala Paas | Skala 1–9 untuk mengukur usaha mental yang dirasakan |
| N-Gain | Peningkatan ternormalisasi: (post − pre) / (maks − pre) |
| Miskonsepsi | Pemahaman keliru yang konsisten |
| Literasi matematika | Kemampuan merumuskan, menerapkan, dan menafsirkan matematika dalam berbagai konteks nyata (PISA) |
| Numerasi | Istilah AKM untuk kemampuan memakai matematika dalam konteks sehari-hari |
| PISA | *Programme for International Student Assessment* (OECD), asesmen internasional untuk siswa usia 15 tahun |
| AKM | Asesmen Kompetensi Minimum, bagian dari Asesmen Nasional Indonesia (literasi membaca dan numerasi) |
| Merumuskan (formulate) | Mengubah situasi nyata menjadi model/masalah matematika |
| Menerapkan (employ) | Memakai konsep dan prosedur untuk mendapatkan hasil |
| Menafsirkan (interpret & evaluate) | Mengembalikan hasil ke konteks dan menilai kewajarannya |
| Pemodelan matematis | Siklus situasi nyata → model matematika → hasil → tafsiran |
| Stimulus | Bahan bacaan nyata (brosur, struk, tabel) yang menjadi dasar soal literasi |
| Pengecoh (distraktor) | Informasi atau pilihan yang tidak dibutuhkan/tidak benar |

## Teknis

| Istilah | Arti |
|---|---|
| PWA (Progressive Web App) | Situs web yang bisa dipasang di HP dan berjalan offline |
| Capacitor | Alat untuk membungkus aplikasi web menjadi aplikasi Android/iOS |
| APK / AAB | Format file instalasi aplikasi Android |
| IndexedDB | Database bawaan browser untuk menyimpan data di perangkat |
| Dexie.js | Library untuk memudahkan pemakaian IndexedDB |
| Service worker | Skrip latar yang membuat PWA bisa offline |
| React | Library JavaScript untuk membuat antarmuka |
| TypeScript | JavaScript dengan tipe data |
| Vite | Alat build dan server pengembangan |
| Tailwind CSS | Kerangka CSS berbasis kelas utilitas |
| Unit test | Pengujian otomatis untuk satu fungsi kecil |
| Seed | Angka awal pengacak agar soal acak bisa diulang persis |
| MVP | *Minimum Viable Product*, versi pertama dengan fitur inti |
| MoSCoW | Prioritas: Must, Should, Could, Won't |
| JavaScript | Bahasa pemrograman web; dipakai untuk aplikasi siswa dan data umum |
| JSDoc | Komentar khusus di JavaScript untuk mendokumentasikan tipe data |
| Python | Bahasa pemrograman; dipakai untuk analisis data statistik |
| pandas | Library Python untuk mengolah data tabel (CSV/Excel) |
| SciPy / statsmodels / pingouin | Library Python untuk uji statistik |
| matplotlib | Library Python untuk membuat grafik |
| Jupyter Notebook | Buku kerja interaktif berisi kode Python, hasil, dan catatan |
| Streamlit | Library Python untuk membuat dasbor web sederhana |
| pytest | Alat pengujian otomatis untuk Python |
| venv | Lingkungan Python terpisah per proyek |
| CSV | File teks berisi tabel, kolom dipisah koma; penghubung data JavaScript → Python |
| Kontrak data | Kesepakatan nama dan format kolom antara pembuat dan pembaca data |
| Sideload | Memasang aplikasi dari file APK di luar Play Store |
| Keystore | File kunci untuk menandatangani APK; wajib sama untuk setiap pembaruan |
| HTTPS | Koneksi web aman; syarat agar PWA bisa dipasang |
| Manifest (web app manifest) | File berisi nama, ikon, dan warna PWA |
| QR code | Kode batang 2D yang dipindai kamera HP untuk membuka alamat web |
| Hosting | Layanan untuk menaruh situs agar bisa diakses lewat internet |
| Mobile first | Merancang untuk layar HP lebih dulu, lalu diperluas ke layar besar |
| dp (density-independent pixel) | Satuan ukuran layar yang sama besarnya di HP dengan kerapatan piksel berbeda |
| Safe area (area aman) | Bagian layar yang tidak tertutup poni, kamera, atau garis navigasi |
| Viewport | Area tampilan halaman web di layar |
| WebView | Komponen browser di dalam aplikasi Android; dipakai oleh APK Capacitor |
| Lighthouse | Alat di Chrome untuk mengukur kinerja, aksesibilitas, dan kualitas PWA |
| Lazy loading | Memuat bagian aplikasi hanya saat dibutuhkan |
| Haptic | Getaran pendek sebagai umpan balik sentuhan |
